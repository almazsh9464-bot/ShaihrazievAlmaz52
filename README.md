# Практические задания по Python

В репозитории собраны практические работы по материалам лекций. Каждая работа сохранена в отдельном Jupyter Notebook (`.ipynb`).

## Список файлов

- `Prakticheskaya_1.ipynb` — ввод, переменные и базовые операции.
- `Prakticheskaya_2.ipynb` — ветвления и циклы.
- `Prakticheskaya_3.ipynb` — списки и словари.
- `Prakticheskaya_4.ipynb` — функции.
- `Prakticheskaya_5.ipynb` — файлы и обработка ошибок.
- `Prakticheskaya_6.ipynb` — основы ООП.

Откройте нужный блокнот и запускайте ячейки с кодом по порядку. Для практической 5 файл `students.json` должен находиться рядом с блокнотом.
